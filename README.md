# Portfólio - Arthur Pereira

Este é meu portfólio pessoal, feito para que recrutadores e pessoas que buscam um serviço na área do desenvolvimento web possam me conhecer. Aqui eu mostro meus projetos, as tecnologias que uso e minhas soft skills.

## O que tem no portfólio

- **Home:** quem eu sou e minha trajetória
- **Tecnologias:** as ferramentas que eu uso
- **Projetos:** meus projetos, com print, descrição e links
- **Soft Skills:** minhas habilidades comportamentais

O layout é responsivo e foi feito com a abordagem mobile first.
